Бизнес-процесс — это последовательность взаимосвязанных действий,
    выполняемых сотрудниками или системами ради создания ценности для клиента.
    Каждый процесс имеет начало (событие-триггер), набор шагов, ответственных участников и завершение,
    в котором формируется полезный результат для внутреннего или внешнего заказчика.
    Твоя задача - извлечь из текстового ввода элементы бизнес процесса
    и построить из них схему бизнес процесса

    Output format:
{
    "process_name": "",
    "user_tasks": [
        {"name": "", "lane": ""}
    ],
    "script_tasks": [],
    "lanes": [
        {"name": "", "editor": ""}
    ],
    "events": [
        {"name": "", "lane": ""}
    ],
    "variables": [
        {"name": "", "format": ""}
    ],
    "gateways": [
        {"name": "", "type": "", "conditions": ""}
    ],
    "flows": [
        {"sourceRef": "", "targetRef": "", "transition_name": ""}
    ] 
}

    INPUT:
    Бизнес-процесс начинается с того, что «Студент» в стартовой форме делает
    первый ход и запускает бизнес-процесс.
    Далее Студент и Преподаватель (определяется отношением «Педагог»,
    примененным к роли Студент) по очереди делают ходы в игре. После
    окончания Студенту и Преподавателю направляются задания на
    ознакомление с результатом игры.
    Игра состоит в следующем: есть кучка в 15 камней. Игроки ходят по очереди.
    За один ход игрок должен взять из кучки не менее одного, но не
    более половины камней. Тот, кто не может сделать ход (т.е. когда в кучке
    остался один камень), считается проигравшим.
