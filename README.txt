Для работы программы нужен python3, основные библиотеки и дополнительные - langchain, openai, python-dotenv, pydantic.

Для их скачивания нужно написать в командной строке, находясь в папке с файлами -
pip install -r requirements.txt

Для запуска программы нужен ключ для api DEEPSEEK, текст бизнес процесса либо элементы бизнес процесса по отдельности. Синтаксис итогового .par файла содержащего .xml файлы соответствует стандартам BPMN систем runaWFE.


Алгоритм запуска программы:
Открыть командную строку.
Перейти в папку с python файлом в терминале.
Написать команду python main.py
result.par сгенерирован


Для проверки достоверности сгенерированного файла можно обратиться к бесплатному online редактору бизнес процессов RunaWFE Online Lite
По ссылке - https://runawfe.ru/RunaWFE_Cloud_Lite

Зарегестрироваться, войти в систему по данным регистрации, затем выбрать в редакторе процессов Process editor, файл со сгенерированным вами процессом.

В редакторе можно свободно менять элементы и передвигать ноды графа бизнес процесса при необходимости.

Реализован модуль генерации файла variables.xml для переменных бизнес-процесса RunaWFE.

Файл variables_builder.py отвечает за:
- ввод списка переменных бизнес-процесса;
- поддержку простых типов переменных;
- поддержку переменных типа List с указанием типа элемента списка;
- указание значения по умолчанию;
- сохранение порядка переменных;
- генерацию variables.xml;
- включение variables.xml в итоговый result.par.

Поддерживаемые типы переменных:
String, Long, Double, Boolean, Date, Executor, File, List.

Формат данных для переменных:
[
    {"name": "amount", "format": "Long", "default": "100"},
    {"name": "comment", "format": "String", "default": ""},
    {"name": "approvers", "format": "List", "element_format": "Executor", "default": "[ivanov, petrov]"}
]

Если format = List, необходимо дополнительно указать element_format.
