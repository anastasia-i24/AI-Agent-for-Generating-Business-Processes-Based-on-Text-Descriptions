Для работы программы нужен Python 3.

Установка зависимостей:
pip install -r requirements.txt

либо pip install openai pydantic python-dotenv langchain

Для запуска программы:
python main.py

Программа может работать в двух режимах:
1. Ручной ввод элементов бизнес-процесса.
2. Генерация структуры бизнес-процесса через LLM по текстовому описанию.

Для режима LLM нужен ключ OpenAI API. Ключ можно передать через переменную окружения OPENAI_API_KEY или ввести при запуске программы.

Результат работы программы — файл result.par.

В result.par входят:
- gpd.xml — графическое расположение элементов процесса;
- processdefinition.xml — BPMN-описание процесса с расширениями RunaWFE;
- variables.xml — роли и переменные бизнес-процесса;
- forms.xml — пустая заготовка форм;
- comments.xml — пустая заготовка комментариев/версий.

Реализована и исправлена часть, отвечающая за генерацию variables.xml.

Файл variables.py отвечает за:
- генерацию variables.xml;
- запись ролей как переменных типа Executor со свойством swimlane="true";
- запись переменных бизнес-процесса;
- поддержку типов Boolean, Long, Double, BigDecimal, String, Text, Date, DateTime, Time, File, Executor, List;
- поддержку значений по умолчанию через defaultValue;
- поддержку переменных-списков с указанием elementFormat;
- прием данных как из ручного ввода, так и из структурированного вывода LLM.

LLM извлекает переменные вместе с остальными элементами бизнес-процесса. После этого данные нормализуются и передаются в variables.py, который формирует variables.xml. Затем все XML-файлы упаковываются в result.par.

Для проверки результата можно импортировать result.par в RunaWFE Online Lite или runawfe-free-devstudio.
