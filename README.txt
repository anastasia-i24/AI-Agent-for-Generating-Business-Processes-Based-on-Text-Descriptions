Для работы программы нужен python3, основные библиотеки и дополнительные - langchain, openai, python-dotenv, pydantic.

Для их скачивания нужно написать в командной строке
pip install langchain openai python-dotenv pydantic
Может еще понадобится добавить эти библиотеки в интерпретатор

Для запуска программы нужен ключ для api OpenAI, текст бизнес процесса либо элементы бизнес процесса по отдельности. Синтаксис итогового .par файла содержащего .xml файлы соответствует стандартам BPMN систем runaWFE.


Алгоритм запуска программы:
Открыть командную строку.
Перейти в папку с python файлом в терминале.
Написать команду python main.py
result.par сгенерирован


Для проверки достоверности сгенерированного файла можно обратиться к бесплатному online редактору бизнес процессов RunaWFE Online Lite
По ссылке - https://runawfe.ru/RunaWFE_Cloud_Lite

Зарегестрироваться, войти в систему по данным регистрации, затем выбрать в редакторе процессов Process editor, файл со сгенерированным вами процессом.

В редакторе можно свободно менять элементы и передвигать ноды графа бизнес процесса при необходимости.
