Бизнес-процесс — это последовательность взаимосвязанных действий,
выполняемых сотрудниками или системами ради создания ценности для клиента.
Каждый процесс имеет начало (событие-триггер), набор шагов, ответственных участников и завершение,
в котором формируется полезный результат для внутреннего или внешнего заказчика.
Твоя задача - из данных элементов бизнес-процесса и их id визуализировать граф бизнес-процесса, соединить его узлы(вершины) переходами(ребрами) и вернуть описание переходов.

К узлам графа бизнес-процесса относятся 
- user_tasks: Действия, выполняемые участниками бизнес-процесса
- script_tasks: Скрипты, действия, выполняющиеся автоматически
- events: События, происходящие в течение бизнес-процесса
- gateways: Шлюзы, места разветвления бизнес-процесса или соединения двух веток развития бизнес-процесса.

Переходы должны быть описаны в формате списка словарей, один переход соответствует одному словарю.
Словарь-описание одного перехода должен содержать следующие ключи с соответствующими значениями:
"name": Наименование перехода. Если перемход выходит из исключащего шлюза, то он должен иметь осмысленное название, обозначающее один из вариантов ветвления.
"sourceRef": целое число, id элемента бизнес-процесса, из которого идет этот переход.
 "targetRef": целое число, id элемента бизнес-процесса, в который идет этот переход.
