Бизнес-процесс — это последовательность взаимосвязанных действий,
выполняемых сотрудниками или системами ради создания ценности для клиента.
Каждый процесс имеет начало (событие-триггер), набор шагов, ответственных участников и завершение,
в котором формируется полезный результат для внутреннего или внешнего заказчика.
Твоя задача - извлечь из произвольного текстового ввода элементы бизнес-процесса

Какие элементы бизнес-процесса необходимо извлечь:
process_name: Название бизнес-процесса в виде одной фразы в формате строки

user_tasks: Действия, которые выполняются участниками бизнес-процесса. 
    Элемент должен быть в формате словаря с ключами "name", который соответствует названию действия (описание выполняемого действия одной фразой),
    и "lane" - участником бизнес-процесса, наименование которого присутствует среди lanes, и без чьего участия выполнение задания невозможно.

script_tasks: Скрипты, действия, которые выполняются автоматически и не требуют вмешательства участников бизнес-процесса. 
    В текстовом описании бизнес-процесса слово "автоматически" чаще всего указывает на описание этого элемента. 
    Эти элементы необязательно могут присутствовать в бизнес-процессе.
    Элемент должен быть в формате словаря с ключом "name", который соответствует названию действия (описание выполняемого действия одной фразой).

lanes: Роли, участники бизнес-процесса, выполняющие действия.
    Элемент должен быть в формате словаря с ключом "name", который соответствует наименованию роли.

events: События, которые происходят в течении бизнес-процесса, обязательно включают в себя стартовое и итоговые события 
    (если бизнес-процесс имеет несколько варинатов окончания, то и итоговых событий может быть несколько).
    Элемент должен быть в формате словаря с ключами "name", который соответствует названию элемента (описание события одной фразой),
    "lane" - участником бизнес-процесса, который инициализировал это событие (этот ключ необязательно может присутствовать) 
    и "type" - тип события, "start" для стартового события и "end" для итоговых событий (для стартовых событий этот ключ является обязательным, для остальных не является).

variables: Переменные бизнес-процесса, все неодушевленные объекты, упоминающиеся в описании бизнес-процесса и используемые при выполнении действий.
    Элемент должен быть в формате словаря с ключами "name", который соответствует названию переменной, и "format", соответствующий формату переменной.
    Переменные могут быть следующих форматов:
    'Boolean': Логическое значение (true/false)
    'Long': Целое число
    'Double': Дробное число
    'BigDecimal': Число повышенной точности
    'String': Строка (одна строка)
    'Text': Текст (многострочный)
    'Date': Дата (без времени)
    'DateTime': Дата и время
    'Time': Время
    'File': Файл
    
gateways: Шлюзы, места, где бизнес-процесс разветвляется (разные варианты) или сходится (разные результаты в один)
    Элемент должен быть в формате словаря с ключами "name", который соответствует названию шлюза, и "type", соответствующий типу шлюза.
    Шлюзы могут быть следующих типов:
        "exclusive": исключающий шлюз, используется, если процесс разветвляется в зависимости от какого-то условия "или".
            После одного исключащего шлюза должен идти другой, в котором два варианта развития событий сходятся в один, либо каждое из условий должно заканчиваться своим итоговым событием.
        "parallel": параллельный шлюз, используется, если процесс разветвляется на две параллельных (одновременных) ветки.
            После одного параллельного шлюза должен идти другой, в котором два параллельные ветки сходятся в одну.
