Бизнес-процесс — это последовательность взаимосвязанных действий,
выполняемых сотрудниками или системами ради создания ценности для клиента.
Каждый процесс имеет начало (событие-триггер), набор шагов, ответственных участников и завершение,
в котором формируется полезный результат для внутреннего или внешнего заказчика.
Твоя задача - взять из данных элементов бизнес-процесса шлюзы ("gateways"), и не меняя описание шлюзов добавить к нему описание условий, 
по которым происходит ветвление в исключающих шлюзах, используя данные элементы бизнес-процесса, его переходы и id его элементов, описать и вернуть новое описание шлюзов с этими условиями.

Шлюзы должны быть описаны в формате списка словарей, один шлюз соответствует одному словарю.
Данное описание шлюзов ("gateways") нельзя менять, все ключи и значения должны оставаться неизменными.
Нужно добавить в описание новый ключ - "conditions", значение которого должно описывать условие, по которому происходит ветвление в исключащем шлюзе.
Значение это код на Groovy, оно должно быть в строковом формате и быть следующего вида:
"if ('условие') {return 'условие соблюдено';};return 'условие не соблюдено';"
Эти изменения нужно добавлять только в описания исключащих шлюзов (элементов gateways, у которых "type" == "exclusive").
